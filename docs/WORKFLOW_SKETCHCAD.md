# SketchCAD → HVAC Grid 따라 하기 (처음 쓰는 사람용)

작성 2026-10-25 · 시험한 판: SketchCAD `ceronfs/SketchCAD` main `a71025a`, HVAC Grid `568d51e` · 시험 도면 `samples/n3/N3_D1.dxf`·`N3_D2.dxf`

받은 일반배치도(DXF)를 **SketchCAD**에서 정리해 실(격실)을 만들고, 그 실을 **HVAC Grid**로 넘겨 부하·풍량·덕트까지 계산하는 순서입니다. 순서대로 따라 하면 되고, 단계마다 **확인** 줄에 적힌 것이 보이면 다음으로 넘어갑니다.

```
받은 DXF
  │
  ▼  SketchCAD (공조 탭)
  ① 계산 준비 ─▶ ② 경계 지정 ─▶ ③ 실 · 면적표 ─▶ "HVAC Grid용 DXF" 저장
  │
  ▼  HVAC Grid
  ① 도면·격실 ─▶ ② 부하 ─▶ ③ 풍량·계통 ─▶ ④ RU·덕트 ─▶ ⑤ 검토·출력
```

**Deck 하나에 도면 하나**입니다. 3층짜리 거주구라면 1부를 Deck마다 한 번씩, 모두 세 번 합니다.

## 0. 준비

| 필요한 것 | 어디에 |
|---|---|
| SketchCAD | 바탕화면 `SketchCAD` 폴더 → `SketchCAD.bat` 더블클릭 (Chrome·Edge 전용 창으로 열림) |
| HVAC Grid | `HVAC_Grid` 폴더 → `HVAC_Grid.bat` 더블클릭 |
| 도면 | Deck별 일반배치도 **DXF**. DWG는 열리지 않으므로 AutoCAD 등에서 DXF로 저장해 둡니다 |

SketchCAD 사용법이 처음이면 `SketchCAD_초보자_매뉴얼.pptx`(같은 폴더)를 먼저 넘겨 보세요. 화면 이동은 **휠 굴리기(확대·축소) / 휠 누른 채 끌기(이동)**, 명령 취소는 **Esc**입니다.

## 1부. SketchCAD에서 실 만들기

### 1-1. 도면 열기

1. `SketchCAD.bat`을 더블클릭합니다.
2. **Ctrl+I**를 누르고 DXF를 고릅니다. 창 안으로 파일을 끌어다 놓아도 됩니다.

**확인**: 아래 명령창에 `객체 ○개, 레이어 ○개를 가져왔습니다`가 나오고 도면이 화면에 꽉 차게 보입니다. 한글 실 이름이 깨지지 않습니다(옛 도면의 EUC-KR 한글도 자동으로 읽습니다).

### 1-2. 계산 준비 — 필요 없는 것 숨기기

1. 리본에서 **공조** 탭을 누릅니다.
2. **① 계산 준비 → 계산용 정리**를 누릅니다.
3. 창 왼쪽 **남길 레이어** 목록에서 **벽, 선체 외곽선, 실 번호·이름 문자** 레이어가 체크되어 있는지 봅니다. 체크된 레이어만 남습니다.
4. 오른쪽 **처리 방법**은 처음엔 **숨기기**를 고르는 것이 안전합니다(기본값은 **삭제**). **문자는 레이어와 관계없이 남김**은 켜 둡니다 — 실 이름을 찾는 데 씁니다.
5. **정리 실행**을 누릅니다.

가구·치수·해치 같은 것이 사라집니다. 잘못 정리했으면 Ctrl+Z, 숨기기로 했으면 **숨긴 객체 복원**으로 되돌립니다.

### 1-3. 경계 지정 — 벽을 알려 주기

레이어 이름에 `BHD`, `PANEL`, `HULL` 같은 말이 들어 있으면 도면을 열 때 이미 지정되어 있습니다. 그렇지 않으면 직접 지정합니다.

1. **② 경계 지정 → 패널 지정**(칸막이 벽) 또는 **BHD 지정**(격벽)을 누릅니다.
2. 명령창에 `L`을 입력하고 Enter → **같은 레이어 전체**로 고르는 상태가 됩니다.
3. 벽 선을 하나 클릭합니다. 그 레이어의 선이 모두 선택됩니다. 벽 레이어가 여러 개면 계속 클릭하고, 다 됐으면 **Enter**.

**확인**: 명령창에 `○개 객체를 패널 레이어 "PANEL"(으로) 지정했습니다`. **경계만 보기**를 누르면 벽만 남아 보입니다(한 번 더 누르면 돌아옴).

> **꼭 하세요 — 벽이 `ROOM` 레이어에 그려진 도면**: SketchCAD는 `ROOM` 레이어를 자기가 만든 실 외곽 자리로 씁니다. 벽이 `ROOM` 레이어에 있으면 이 단계를 건너뛸 때 실을 거의 찾지 못합니다(시험: 29실 중 1실). 벽을 패널로 지정하면 모두 찾습니다(29실 중 29실).

### 1-4. 실 만들기

1. **③ 실 · 면적표 → 실 자동 찾기**를 누릅니다.
2. 도면의 실 이름 문자를 둘러싼 벽을 찾아 목록으로 보여 줍니다. 번호·이름·면적을 훑어보고, 이상한 줄은 체크를 끕니다.
3. **실 만들기**를 누릅니다.

**확인**: 명령창과 오른쪽 아래 알림에 `실 ○개를 만들었습니다 (합계 ○ m²)`. 실마다 `ROOM` 레이어에 닫힌 외곽선이 생깁니다.

자동으로 못 찾은 실(이름 문자가 없는 실 등)은 **실 지정**을 누르고 그 실 안쪽을 클릭 → 번호 입력 → 이름 입력. Esc로 끝냅니다.

### 1-5. 면적표 확인하고 HVAC Grid용으로 저장

1. **③ 실 · 면적표 → 면적표·내보내기**를 누릅니다.
2. 실 번호·이름·면적을 확인합니다. 칸에서 바로 고칠 수 있고, 고치면 도면의 문자도 바뀝니다. 돋보기를 누르면 그 실로 화면이 갑니다.
3. 오른쪽 위 파란 단추 **HVAC Grid용 DXF**를 누르고 저장합니다.

**파일 이름**은 `배이름_Deck이름` 식으로 알아보기 쉽게 붙이세요(예: `N3_D2_rooms_hvacgrid.dxf`). HVAC Grid가 이 파일 이름을 Deck의 처음 이름으로 씁니다.

마지막으로 **Ctrl+S**로 SketchCAD 작업 파일(JSON)도 저장해 두면 나중에 고치기 쉽습니다.

**실 번호는 숫자로**: HVAC Grid(BOX)는 숫자로만 된 문자를 실 번호로 읽습니다. `211T`처럼 글자가 붙으면 번호가 비고 이름 앞에 붙습니다(`docs/TEST_DRAWINGS.md` v2.2). 면적표에서 숫자 번호로 고쳐 두세요.

## 2부. HVAC Grid에서 계산하기

`HVAC_Grid.bat`을 더블클릭하면 HVAC Grid 창이 열립니다. 위의 **① ~ ⑤** 단추가 작업 순서이고, 맨 아래 상태 줄의 **다음:** 단추가 지금 할 일을 알려 줍니다. 막히면 **F1(도움말)**.

### 2-1. ① 도면·격실 — SketchCAD에서 만든 DXF 열기

1. **① 도면·격실**에서 리본 왼쪽 **DXF 열기**를 누르고 1-5에서 저장한 파일을 고릅니다.
2. Deck이 여러 개면 Deck마다 **DXF 열기**를 반복합니다. 열 때마다 오른쪽 Deck 목록에 Deck이 하나씩 늘어납니다.

**확인**: 실마다 색이 칠해지고 번호·이름이 보입니다. 아래 상태 줄 오른쪽에 `ROOM 29/29`처럼 **두 숫자가 같고**, 그 숫자가 SketchCAD 면적표의 실 개수와 같습니다.

### 2-2. Deck 이름·높이

오른쪽 Deck 목록에서

1. Deck 이름을 **더블클릭**하고 이름(예: `CREW DK`)을 입력합니다.
2. **Z**(갑판 높이, mm — 맨 아래 Deck 0)와 **H**(층 높이, mm)를 입력합니다.

### 2-3. 선체 외곽선 지정

1. 리본 **하부 외곽선**을 누르고, 선체 쪽 바깥 테두리 선을 **변마다 하나씩** 클릭합니다.
2. **상부 외곽선**도 같은 선들을 똑같이 클릭합니다.
3. **외곽선 검증**을 눌러 빠진 변이 없는지 봅니다.

클릭은 **실 모서리에서 조금 떨어진 곳**에 합니다. 모서리를 누르면 안쪽 벽이 잡힐 수 있습니다.

### 2-4. ② 부하

1. **② 부하**로 갑니다.
2. **격실 입력**: 실마다 계통(급기·배기·환기), 인원, 장비 발열, 천장 높이 등을 넣습니다. 엑셀 표를 복사해 붙여넣을 수 있습니다.
3. **설계 조건**: 외기·실내 조건, 흘수선 적용 여부 등을 확인합니다.
4. **격실 부하**에서 계산 결과를 보고, 리본 **설계 데이터 만들기**를 누릅니다.

**확인**: 모든 실의 부하 계산이 완료로 나옵니다(미완료 0).

### 2-5. ③ 풍량·계통

1. **③ 풍량·계통**에서 계통별 풍량과 공조기 위치·공조기 Deck·샤프트를 확인합니다. 팬룸이 없는 Deck의 팬은 **위치 지정**을 누르고 놓을 실을 클릭합니다.
2. 풍량은 **여름(냉방) 기준 하나**로 정해집니다. 겨울은 같은 풍량으로 운전하고, 난방은 공조기 히터·재열기 **난방 용량**으로 봅니다. 겨울 풍량을 따로 넣지 않습니다(`AGENTS.md` F-1).

### 2-6. ④ RU·덕트, ⑤ 검토·출력

1. **⑤ 검토·출력**의 방화(SOLAS) 탭에서 **최하층 아래**를 고릅니다(예: 기관실 — A류).
2. 리본 **모든 계통 AUTO**를 누릅니다. 계통 수에 따라 1분 안팎 걸립니다.
3. **④ RU·덕트**에서 덕트망을 봅니다. RU·공조기를 끌어 옮기거나 덕트 크기를 바꾸면 다시 계산합니다.
4. **⑤ 검토·출력**에서 검토(통과·확인 필요·실패)를 보고, **프로젝트 저장**, **통합 XLSX**, **통합 DXF**, **보고서**를 내려받습니다.

## 자주 막히는 곳

| 증상 | 원인과 할 일 |
|---|---|
| SketchCAD **실 자동 찾기**가 실을 거의 못 찾음 | ① 벽이 `ROOM` 레이어에 있음 → 1-3에서 패널로 지정. ② 경계 지정을 안 함 → 1-3. ③ 문 틈이 넓어 실이 닫히지 않음 → **실 지정** 명령에서 `G`로 문 틈 폭(기본 1,000 mm)을 늘림 |
| 두 실이 하나로 합쳐짐 | 사이 벽이 끊겨 있거나 숨겨짐 → 계산용 정리에서 벽 레이어를 남겼는지 확인, 끊긴 곳에 선을 그어 막음 |
| 실 이름이 비어 있음 | 실 안에 이름 문자가 없음 → 면적표에서 이름을 입력 |
| HVAC Grid에서 실 번호가 "미지정" | 번호에 글자가 섞임(`211T`) → SketchCAD 면적표에서 숫자 번호로 고쳐 다시 저장 |
| HVAC Grid 상태 줄 `ROOM 27/29`처럼 두 숫자가 다름 | 일부 실이 읽히지 않음 → SketchCAD 면적표의 실 개수와 비교하고, 빠진 실을 SketchCAD에서 다시 만들어 저장 |
| DWG 파일 | 열 수 없음 → DXF로 바꿔서 |
| 한글이 깨짐 | SketchCAD는 EUC-KR 도면을 자동으로 읽음. 그래도 깨지면 원본 프로그램에서 DXF 2007 이상(UTF-8)으로 다시 저장 |

## 시험 기록 (2026-10-25)

SketchCAD에서 도면 열기 → (필요하면 패널 지정) → 실 자동 찾기 → HVAC Grid용 DXF 저장 → HVAC Grid ① DXF 열기까지 Edge로 자동 실행했습니다. 같은 시험을 `npm run test:sketchcad`(`test/e2e/sketchcad.e2e.cjs`, `npm run test:e2e`에 포함)로 다시 돌릴 수 있습니다. SketchCAD는 이 저장소 옆 `../SketchCAD/SketchCAD.html` 또는 `SKETCHCAD_HTML`에서 찾고, 없으면 건너뜁니다. 결과와 캡처는 `out/e2e-sketchcad/`.

| 도면 | SketchCAD 실 | HVAC Grid 판독기(`lib/dxf-in.cjs`) | HVAC Grid ①(BOX) | 원본과 대조 |
|---|---|---|---|---|
| `N3_D2.dxf`, 벽 레이어를 `WALL`로 바꿈(받은 도면 가정) | 29 | 29 | 29 | 번호·이름·면적 모두 같음 |
| `N3_D2.dxf` 그대로(벽이 `ROOM` 레이어) | **1** | 1 | 1 | 1-3 패널 지정을 건너뛴 경우 |
| 위와 같은 도면 + 벽을 패널로 지정 | 29 | 29 | 29 | 같음 |
| `N3_D1.dxf`(R12, EUC-KR 한글), 벽 `WALL` | 19 | 19 | 19 | 번호·이름·면적 모두 같음 |

대조 기준은 `samples/n3/N3.inputs.json`입니다. SketchCAD와 판독기는 번호·이름·면적(차이 0.01 m² 미만), BOX는 번호·이름을 봅니다.

페이지 오류 0. 시험한 범위는 **HVAC Grid ①에서 실을 읽는 데까지**입니다. ② 부하부터 ⑤ 출력까지는 DXF 도면으로 시작하는 N3 시험(`npm run test:n3`, `docs/TEST_DRAWINGS.md`)이 같은 경로로 확인합니다.
