## 3. 잘된 점

- **단계 탭이 리본과 이어지는 구조**: 선택된 탭이 리본 바탕(#fff)과 붙고, ✓·● n·n/17 배지로 진행이 한눈에 보입니다(`07-air-room-1600-light`, `z01-header-light`).
- **토큰 기반 셸**: 밝은 화면 본문 14.6:1, 보조 7.1:1, 선택 행 위 보조 6.2:1. 웜 다크 셸 토큰도 본문 13.2:1, 보조 6.5:1입니다(`contrast.txt`).
- **평면 라벨**: 실 번호 600 굵기 + 풍량 400, 후광(`paint-order:stroke`), 좁은 실은 번호만. 전달 공기 화살표와 CMH, A급 경계 통과는 주황으로 구분합니다(`z21-xfer-114`).
- **속성 카드**: 형상 → 부하 → 풍량 → 계통 → RU·덕트 → 방화 순서가 고정되어 있고, 값의 출처(BOX / BOX CAL / HVAC Grid / PHG D)가 작은 회색으로 붙어 있습니다. 652 W 같은 핵심 값만 20 px입니다(`z16-inspector-dark`).
- **⑤ 검토**: 실패 → 확인 → 통과 접기, 분야별 묶음, 방화 등급 칩 필터, 관통 행 → ③ 위치 이동(`16-review-checks-1600-light`, `16-review-fire-1600-light`).
- **④ 안내 카드**: 빈 PHG D 위에 "보내기 + AUTO / 보내기만 / 모든 계통 AUTO / 직접 그리기"가 뜹니다(`10-duct-guide-1600-light`).
- **진행 상자**: 진행 막대·남은 시간·멈춤이 있습니다(`14-progress-1600-light`).
- **도움말**: 작업 순서·단축키·용어·파일·문제 해결이 한 대화상자에 있고, 용어에 급기(SA) 같은 약어가 붙어 있습니다(`17-help-1600-light`).

1. **바로(S, 합계 2~3일)** — 값만 바꾸는 것부터
   - D-05 어두운 화면 채움 토큰, D-11 호버·포커스, D-12 주 버튼 하나, D-13 숫자·Deck 이름, D-14 표 정렬, D-06 1280 표·패널, D-08 오류 알림 닫기·칸 말풍선, D-32·D-31·D-26·D-33
   - D-04 라벨을 마지막 층으로 그리기(그리기 순서만 바꿔도 대부분 해결)
2. **다음(M)** — 화면 인상을 바꾸는 것
   - D-03 평면 색 의미(선택 = 모양, 전달 공기 = 회색, 덕트 = 진한 계통색) → D-18 방화 등급 색과 함께
   - D-02 CAL 패널 닫기·코드 줄 숨김·빈 상태
   - D-07 보고서 인쇄(쪽 나눔, 머리·꼬리·쪽 번호, 표제란, 9.5 px) → D-24 보고서 일관성
   - D-09 알림 체계, D-10 대화상자 문구, D-21 상태 정직성, D-23 ① 빈 시작, D-22 브라우저 흔적
3. **그다음(M~L)** — 한 제품으로 보이게
   - D-01 어두운 화면을 원본 앱까지(BOX → PHG D 순), D-16 원본 앱 타이포·컨트롤, D-15 ①②④ 레이아웃, D-17 덕트 색 언어
   - D-19·D-20 검토·방화 연동, D-25 ④ 선택 강조
4. **다듬기** — D-27~D-30, D-34~D-37

1단계와 2단계를 마치면 색·대비 B+, 대화상자·알림 B+, 평면 표현 A-, 보고서 B+로 보고 종합 B+입니다. 3단계의 D-01·D-16까지 하면 "세 앱을 붙인 화면"이 아니라 한 제품으로 읽혀 A-가 됩니다.

## 6. 가장 중요한 변경의 전후 스케치 (D-03 + D-04, ③ 평면)

지금(`z04-plan-labels`): 선택·덕트·전달 공기·계통 채움이 모두 파랑이고, 덕트와 화살표가 실 번호 위를 지납니다.

```
 ┌──────────┬────────────┐        파랑 ███ 실 채움(계통 AHU-ACC)
 │205 ↓50   │206         │        파랑 ─── 덕트 (실 번호 "211T" 위를 지남)
 │  (화살표가│            │        파랑 ═══ 선택한 실 211 테두리
 │   번호에) │            │        파랑 - → 전달 공기 110
 ├──────────┼─┬──────────┤
 │211T  ←110│ │212T ←110 │   →  "어느 파랑이 무엇인지" 범례를 읽어야 앎
 │   │      │ │   │      │
 ╞═══╪══════╡ ├───┼──────┤
 ║211│200CMH║ │212│      │
```

바꾼 뒤: 선택은 모양(검정 점선 + 모서리 그립), 덕트는 진한 계통색 + 캔버스색 밑선, 전달 공기는 회색, 라벨은 맨 위.

```
 ┌──────────┬────────────┐        연파랑 (6 %) 실 채움, 현재 계통만 14 %
 │205       │206         │        진파랑 ━━━ 덕트 3 px / ── 1.75 px, 라벨 앞에서 끊김
 │ 50 ↓     │            │        회색 - → 전달 공기, 숫자는 라벨과 겹치면 반대편
 ├──────────┼─┬──────────┤        ■┄┄┄■ 선택: 후광 7 px + 검정 2 px 점선 + 그립 7 px
 │211T 110← │ │212T 110← │
 │  ━━┃━━━  │ │  ━━┃━━━  │   →  색 = 데이터(계통·등급), 모양 = 상태(선택·임시)
```
