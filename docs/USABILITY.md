## 3. 잘 된 점 (유지)

- 단계 탭(①~⑤)과 완료 ✓, 검토 배지(● 5)로 어디까지 했는지 보입니다.
- 설계 데이터가 없을 때 각 단계에 "아직 설계 데이터가 없습니다 + 무엇을 누를지" 안내가 나옵니다.
- 왼쪽 실 목록·가운데 평면·오른쪽 실 정보(형상 → 부하 → 풍량 → 계통 → 방화)가 모든 단계에서 같은 자리에 있습니다.
- 검토가 통과·확인·실패 3단계이고, 확인 사항은 분야별로 묶여 있습니다.
- 긴 작업 중에는 진행 표시(1/17 · D1 · AHU-ACC AUTO)가 나옵니다.
- 어두운 화면, 1280 px 리본 넘김 버튼, 독립 창 실행이 있습니다.
