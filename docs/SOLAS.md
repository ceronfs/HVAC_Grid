작성 2026-10-19 · 구현 `lib/solas.cjs` · 데이터 `lib/solas-data.json` · 테스트 `test/solas.test.cjs`

PHG D SOLAS 적용 계획(`PHG/docs/PHG_D_SOLAS_APPLY_PLAN.md`, P1~P4)을 **HVAC Grid의 공유 격실 모델**(BOX 격실 = 계약 `rooms`)에 연결했습니다. PHG D가 도면에서 실을 다시 찾는 대신, BOX가 정의한 격실과 Deck 높이를 그대로 써서 **격벽·외벽·갑판** 경계와 **Deck 덕트·수직 덕트** 관통을 판정합니다. 설계 보조이며 최종 판단은 주관청·선급입니다.

## 2. 실 분류

순서: 사용자 지정(`contract.solas.rooms[roomId].space`) → 실 이름 → BOX ISO 분류(WHEELHOUSE·ALLEY·ENGINE·BOILER·CONTROL).

- 이름 사전(`SYNONYMS`): 한국어·영어 실명 → 82종 격실(+ HVAC Grid 추가 4종: 냉동기계실, 펌프실(기관구역), 오수처리실, 축전지실 — 모두 기타 기관구역).
- **한국어 복합어는 마지막 단어가 용도**: 이름에서 *가장 뒤에서 끝나는* 일치를 고르고, 같으면 더 긴 일치. 예) 선교화장실 → 화장실, 사관식당 → 식당, 냉동기계실 → 냉동기계실, GALLEY ≠ ALLEY, 비상발전기실 ≠ 발전기실.
- 면적으로 갈리는 격실: 창고(4 m²), 세탁실·건조실(4 m²), 공공장소(50 m²).
- 사전에 없는 실은 **미분류**: 경계 등급 "미정", 관통 "판정 보류". 셸 ⑤ 방화 탭 또는 격실 속성에서 공간을 지정하면 즉시 다시 판정(실행 취소 가능). S5 94실 중 미분류 3실(관측실·예비실·소화장비실), T3 73실 중 3실(덕트 트렁크).

## 3. 경계

| 종류 | 찾는 법 | 표 |
|---|---|---|
| 격벽 | 같은 Deck 두 실의 변이 평행(≤ 1.1°), 간격 ≤ 400 mm(벽 두께), 겹침 ≥ 100 mm → 겹친 구간이 경계 | 9.1/9.3/9.5/9.7 (대칭) |
| 외벽 | 실의 변 중 다른 실이 덮지 않는 구간(≥ 500 mm) → 개방갑판 범주와의 경계 | 같은 표 |
| 갑판 | 바로 위 Deck의 실과 평면상 겹침 ≥ 0.5 m² (200 mm 격자 표본) → (아래 실, 위 실) | 9.2/9.4/9.6/9.8 (비대칭) |

등급 결정(기본값은 PHG D 계획의 임시 기본값과 같음):

- 선종 기본 **화물선(Table 9.5/9.6)**, 방화방식 **IC** — 셸 ⑤ 리본에서 변경(여객선 36명 초과·이하, 탱커).
- 두 값 병기(`B-0|A-0^c` 등): 화물선·탱커는 **엄격한 값** + "갑판까지 연장되는지 확인" 표시, 여객선 36명 이하는 스프링클러 설정으로 선택.
- 같은 범주의 "용도가 다를 때만" 주석: 두 실의 SOLAS 공간이 같으면 요건 없음(-), 다르면 표 등급.
- 화물선 주석 a(IIC·IIIC는 격벽 요건 없음), b(IIIC 50 m²) 반영. 경계별 사용자 등급(`contract.solas.bounds[id].grade`) 우선.

## 4. 관통 (II-2/9.7.3)

| 경계 | 덕트 단면적 | 조치 |
|---|---|---|
| A급 | ≤ 0.02 m² | 강재 슬리브 3t × 200 |
| A급 | > 0.02 m² | 강재 슬리브 3t × 900 + 경계 등급 단열 |
| A급 | > 0.075 m² | 위 + **자동 방화댐퍼** |
| B급 | > 0.02 m² | 강재 슬리브 900 (그 길이가 강재 덕트면 생략) / 이하는 밀폐 |
| `*` | — | 강 또는 동등재, 관통부 밀폐 |
| C · `-` | — | 요건 없음 |

- Deck 덕트: PHG D가 크기를 정한 덕트 구간(셸이 읽은 `geometry`)과 격벽·외벽 경계의 교차점. 크기 미산정이면 "크기 산정 후 판정".
- 수직 덕트: 공조기 Deck에서 샤프트까지의 **수평 이동부**(x 먼저 / y 먼저 중 경계를 덜 지나는 L자)는 격벽 관통, **수직부**(먼 쪽 샤프트 위치)는 지나는 모든 갑판의 갑판 관통.
- 단면적은 공칭 크기 기준(SOLAS는 내측 치수) — 단열 두께만큼 작아지는 실제 값은 설계자가 확인.
- 계통 경고(II-2/9.7.2.1·9.7.5): 조리실 또는 A류 기관구역을 거주·업무구역과 같은 계통이 담당하면 경고. S5의 SUP-ER-02(기관구역 + 기관제어실)가 해당.
