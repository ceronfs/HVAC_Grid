# SOLAS II-2 방화 판정 (H4)

작성 2026-10-19 · 1차 리뷰 반영 · 구현 `lib/solas.cjs` · 데이터 `lib/solas-data.json` · 테스트 `test/solas.test.cjs`

PHG D SOLAS 적용 계획(`PHG/docs/PHG_D_SOLAS_APPLY_PLAN.md`, P1~P4)을 **HVAC Grid의 공유 격실 모델**(BOX 격실 = 설계 데이터 `rooms`, 선박 좌표)에 연결했습니다. PHG D가 도면에서 실을 다시 찾는 대신, BOX가 정의한 격실과 Deck 높이를 그대로 써서 **격벽·외벽·갑판·바닥·천장** 경계와 **Deck 덕트·수직 덕트** 관통, **제한 구역 통과**를 판정합니다. 설계 보조이며 최종 판단은 주관청·선급입니다.

## 2. 실 분류

순서: 사용자 지정(`contract.solas.rooms[roomId].space`, 셸 ⑤·격실 속성) → 실 이름 → BOX ISO 분류(WHEELHOUSE·ALLEY·ENGINE·BOILER·CONTROL).

- 이름 사전(`SYNONYMS`): 한국어·영어 실명 → 82종 + HVAC Grid 추가 7종(냉동기계실·펌프실(기관구역)·오수처리실·축전지실 = 기타 기관구역, **항해·통신 장비실 = 제어장소**(II-2/3.18), **덕트 트렁크** = 기타 기관구역, **식료품 냉장고** = 창고).
- **한국어 복합어는 마지막 단어가 용도**: 이름에서 가장 뒤에서 끝나는 일치, 같으면 더 긴 일치. 선교화장실 → 화장실, 사관식당 → 식당, GALLEY ≠ ALLEY, 비상발전기실 ≠ 발전기실, 비상탈출트렁크 ≠ 덕트 트렁크.
- 면적: 창고 **4 m² 이상** 고위험, 세탁실·건조실 4 m², 공공장소 50 m².
- 분류 확인 표시: 축전지실(GMDSS·비상전원이면 제어장소), 전기설비실(주항해·무선 장비면 제어장소), 냉장실·식료품 냉장고, 덕트 트렁크(트렁크 벽이 갑판 성능을 이음).
- 사전에 없는 실은 **미분류**(경계 "미정", 관통 "판정 보류"). S5 94실 중 3실, T3 79실 중 0실.

## 3. 경계

| 종류 | 찾는 법 | 표 |
|---|---|---|
| 격벽 | 같은 Deck 두 실의 변(외곽·**구멍** 모두)이 평행(≤ 1.1°), 간격 ≤ 400 mm, 겹침 ≥ 100 mm | 9.1/9.3/9.5/9.7 (대칭) |
| 외벽 | 외곽 변 중 다른 실이 덮지 않는 구간(≥ 500 mm) → 개방갑판 | 같은 표 |
| 구멍 | 구멍 변 중 어느 실도 채우지 않은 구간 → 모델 밖, **판정 보류** | — |
| 갑판 | 바로 위 Deck 실과 평면 겹침 ≥ min(0.5 m², 작은 실의 절반) → (아래, 위) | 9.2/9.4/9.6/9.8 (비대칭) |
| 바닥 | 아래 Deck 실이 덮지 않는 바닥 ≥ 0.5 m²: 최하층은 **최하층 아래 공간**(⑤ 설정, 미지정이면 보류), 그 위는 개방갑판(돌출부, 확인) | 갑판 표 |
| 천장 | 위 Deck 실이 덮지 않는 천장 ≥ 0.5 m² → 개방갑판(지붕·노출 갑판) | 갑판 표 |

등급 결정:

- 선종 기본 **화물선(Table 9.5/9.6)**, 방화방식 **IC** — ⑤ 리본에서 선종·방화방식·최하층 아래·스프링클러.
- 두 값 병기:
  - **계단 칸**(화물선 주석 c, 탱커 a, 여객 36명 이하 a): 관통하는 갑판 수 = 계단실이 이어진 Deck 수 − 1(위아래 Deck에서 0.5 m² 넘게 겹치는 계단실을 쌓아 셈). **2개 이상**이면 엄격한 값(A-0), **1개**면 완화 값(B-0) + 확인(II-2/9.2.3.4 등). 계단이 모델의 맨 위·맨 아래 Deck에서 끝나면 모델 밖으로 이어질 수 있으므로 엄격한 값 + 확인.
  - **스프링클러 칸**(여객 36명 이하 주석 d): 양쪽 설치면 작은 값, 아니면 큰 값 + 확인.
  - 그 밖: 엄격한 값 + 해당 조항 확인.
- 같은 범주의 "용도가 다를 때만": 두 실의 SOLAS 공간이 같으면 요건 없음(-). 여객 36명 초과 주석 a(생략 가능)는 확인만.
- 화물선 주석 a(IIC·IIIC는 격벽 요건 없음)·b(IIIC 50 m²) 반영. 탱커 거주구 외벽은 9.2.4.2.5(A-60) 확인. 경계별 사용자 등급(`solas.bounds[id].grade`, id = 실 쌍 + 좌표) 우선.

## 4. 관통 (II-2/9.7.3)

| 경계 | 덕트 단면적 | 조치 |
|---|---|---|
| A급 | ≤ 0.02 m² | 강재 슬리브 3t × 200 |
| A급 | > 0.02 m² | 강재 슬리브 3t × 900 + 경계 등급 단열(A-0은 단열 없음) |
| A급 | > 0.075 m² | 위 + **자동 방화댐퍼** |
| B급 | > 0.02 m² | 강재 슬리브 900 (그 길이가 강재 덕트면 생략) / 이하는 밀폐 |
| `*` | — | 강 또는 동등재, 관통부 밀폐 |
| C · `-` | — | 요건 없음 |

- Deck 덕트: PHG D가 크기를 정한 덕트 폴리라인과 격벽·외벽 경계의 **교차**(꼭짓점이 벽 위면 양쪽으로 넘어갈 때만, 벽을 따라 가거나 닿고 돌아가면 아님). 같은 덕트 50 mm 안의 관통은 하나(T자 모서리, 엄격한 등급).
- 수직 덕트: 공조기 Deck의 수평 이동부(x 먼저 / y 먼저 중 경계를 덜 지나는 L자)는 격벽 관통, 수직부(먼 쪽 샤프트 위치)는 지나는 모든 갑판의 갑판 관통. **트렁크가 아닌 실을 수직 관통하면 확인**. 수직 덕트의 방화댐퍼는 그 구간 압력손실에 K 0.3으로 더함.
- 단면적은 공칭 크기 기준(SOLAS는 내측 치수).

## 5. 제한 구역 통과 (II-2/9.7.2)와 점검표

- AUTO 전에, 계획이 담당하지 않는 **A류 기관구역·보일러실·조리실·CO₂실·계단·축전지실·페인트 로커·가연성 액체 창고·램프실**을 PHG D 금지 영역(벽에서 50 mm 안쪽)으로 넣습니다. Deck의 실 밖(개방갑판·600 mm 넘는 홈, 실 범위 둘레 10 m 띠)도 금지 영역으로 넣습니다. 모든 RU에 닿는 경로가 없으면 실 밖 영역만 풀고(제한 구역 유지) → 제한 구역만 풀고(실 밖 유지) → 모두 풀고 순서로 다시 AUTO하며 "금지 영역 해제(선체 밖 / 제한 구역 / 전부)"로 표시합니다. 실 사이 벽 틈(600 mm 미만)은 실 밖으로 보지 않습니다.
- 조리실 **배기** 계통은 담당하지 않는 다른 실을 모두 금지 영역으로 넣습니다(팬룸·덕트 트렁크만 지남, 9.7.5: 거주구를 지나는 조리실 레인지 배기 덕트는 A급 구조). 조리실 급기는 일반 제한 구역만 피하고, 거주구를 지나면 확인.
- 결과 덕트가 어느 실에도 속하지 않는 곳(모든 실 벽에서 300 mm 넘게 밖)을 0.3 m 이상 지나면: 사방에 실이 있는 Deck 안(모델에 없는 파이프 덕트·로비 등)이면 **확인**("모델에 없는 공간 — 격실로 추가"), Deck 외곽 밖이면 **실패**("실 밖으로 지나는 덕트" 검토 항목, 외벽 두 번 관통).
- 결과 덕트가 담당하지 않는 실을 0.3 m 이상 지나면: 제한 구역이면 **실패**(계단은 확인), 조리실·A류 기관구역 계통 덕트가 거주·업무구역을 지나면 **확인**(A급 구조·방화댐퍼 조건).
- 계통 분리(II-2/9.7.2.1): 조리실·A류 기관구역·화물구역 계통이 그 밖의 공간을 하나라도 담당하면 실패(조리실 부속 팬트리 허용).
- 점검표: 조리실 배기 9.7.5(그리스 트랩·하단 방화댐퍼·팬 정지·덕트 소화, 거주구 통과 길이 → A급 구조), 축전지실·CO₂실(배기·환기 공용이면 실패, 배기 없으면 실패/확인, 급기만 공용이면 확인), 통풍 정지·폐쇄(II-2/5.2.1).

## 6a. 방화 등급도 (2026-10-21)

판정 결과를 **글자로 적은 Deck 평면**. 기존 평면(③ 방화 보기, 통합 DXF, 보고서 평면)은 등급을 색·선 굵기·레이어로만 구분해 흑백 인쇄나 제출 도면으로 읽을 수 없어서, 별도 기능으로 만들었다(`lib/fire-plan.cjs`).

- 실마다: "번호 이름", "(범주) 공간"(선종의 범주 번호와 이름), 바닥·천장 등급(A·B급 — 아래·위 실이 여럿이면 가장 엄한 등급에 "등"). 미분류 실은 노란 빗금.
- 벽: 같은 Deck·같은 등급·같은 종류(격벽/외벽)이고 한 직선 위에 60 mm 안으로 이어진 경계 조각은 **한 줄(run)**로 합쳐 가운데에 한 번 표기(벽 방향으로 회전). 1 m 미만 줄은 표기 생략, C급과 외벽(*)은 기본 생략(화면에서 켤 수 있음). 등급 미정 경계는 주황 점선.
- 관통: 번호·등급·FD(방화댐퍼)/SL(슬리브 mm). 화면에서는 실 이름과 겹치지 않는 쪽에 붙임.
- 출력: ⑤ 검토·출력의 **"방화 등급도"** 탭(Deck 선택, C급·외벽 표기, DXF 저장), 리본 출력 **"방화 등급도 DXF"**(R12, 모든 Deck 나란히, 오른쪽에 범례 — 선은 등급별 레이어 `FIRE_A60`·`FIRE_A0`·`FIRE_B0` …, 등급 글자는 `FIRE_TEXT_*`, 범주 `FIRE_CAT`, 바닥·천장 `FIRE_DECK_TEXT`, 관통 `FIRE_PEN*` — 레이어별로 켜고 끔), 보고서의 Deck별 "방화 등급도" 쪽, `hvac-run`의 `fire-plan.dxf`.
- 시험: `test/fire-plan.test.cjs`(모델·줄 합치기·SVG·DXF), `test/e2e/fireplan.e2e.cjs`(화면). DXF는 ezdxf 감사 오류 0(R12).

## 7. 검사하지 않는 것 (한계)

- 주수직구역·수평구역(여객선), 위험물 화물, 실별 스프링클러 구분 — 설정이나 확인 표시로만.
- II-2/9.7.1 덕트 재질(불연재, 짧은 가연 덕트 ≤ 0.02 m²·2 m)과 9.7.3의 방화댐퍼 면제 조건 — 덕트 재질 데이터가 없음.
- II-2/9.4.2 문 통기구는 복도 → 화장실 등 전달 공기 면적(2 m/s)으로만 확인.
- 방화댐퍼 손실은 수직 덕트에만 반영(Deck 덕트망 안의 방화댐퍼는 PHG D 압력 계산 계획 4-4).
- 단면적의 내측 치수(단열 두께) 보정, 갑판 등급 해치 표현(DXF는 외곽선).
