# H1 결과 — S5 예제: BOX 부하 → PHG D 덕트망

실행 2026-10-18 · `node tools/phg-generate.cjs samples/s5.contract.json out/s5 --auto`
원본: `vendor/BOX_CAL_Enhance.html`(bd942611), `vendor/DuctConcept_PHG_D.html`(643f328a) — 원본 파일은 읽기 전용, 결과는 `out/s5/`(git 제외)

## 흐름

1. 설계 데이터(`samples/s5.contract.json`)의 급기 계통마다, 계통이 쓰는 Deck별로 PHG D 프로젝트 1개
2. Deck 격실 → DXF(닫힌 외곽선 ROOM + 실 번호·이름 문자) → PHG D 배경 도면으로 가져오기
3. Root: 같은 Deck의 팬룸·공조기실, 없으면 복도 끝(**임시 — 실제 공조기 위치로 옮겨야 함**)
4. RU: 격실 급기 풍량 500 CMH마다 1개, 실 안 중심(또는 가장 안쪽 점), Root·다른 RU와 400 mm 이상, 풍량 합계 보존
5. `--auto`: PHG D AUTO → 덕트 지정 → 계산 → 압력 계산, 화면 캡처
