"기준값을 다시 뽑아도 같다": 1.0 기준값은 처음 만든 뒤 `--check`를 두 번(면 행을 더하기 전과 뒤), PHG 기준값은 한 번 돌렸고 모두 같았다. 같게 만들려고 정규화한 것(값을 버린 것이 아니라 바꿔 적은 것):

| 무엇 | 왜 | 어떻게 |
|---|---|---|
| 결과 `at`·`seconds`, `savedAt` | 실행 시각·시간 | `at: 1`, `seconds: 0`, `savedAt: '-'` |

| BOX 면 id `F:<md5>` | 데크 id를 해시함 | 처음 나온 순서대로 `F:#n` |
| 보고서 HTML의 만든 시각 | `lib/util.cjs` `localTime()` | 해시 전에 `YYYY-MM-DD hh:mm`로 가림 |
| PHG D 임의 id, 시간 필드, `…Ms` 숫자, `phgdParallel` | 실행·기계마다 다름 | 처음 나온 순서 번호, 0, `'-'` |
| PHG D 워커 메시지 순서 | 경로 워커 여럿이 동시에 돌아 답이 아무 순서로 옴 | 계획마다 (워커, in → out, 메시지 내용) 순으로 정렬 — 어느 답이 어느 요청의 것인지는 남지 않음 |

## 7. 확인하지 못한 것

- `npm run test:e2e`(Edge e2e 묶음)는 이 단계에서 돌리지 않았다. 기준값 도구가 같은 셸 경로(BOX → CAL → 설계 데이터 → SOLAS → 모든 계통 AUTO)를 S5·T3·N3로 여러 번 돌렸고 페이지 오류 0, AUTO 전부 완료.
- 브라우저는 Edge가 아니라 Chromium(Linux)이다. 사용자 PC(Windows, Edge)에서 `npm run golden:check`로 같은 값이 나오는지 확인이 필요하다(부동 소수 차이·글꼴과 무관한 계산이지만 확인 전).
- BOX CAL 자체 시험(기록상 110건)과 BOX 호스트 시험은 돌리지 않았다.
- ISO 7547·ASHRAE·SOLAS 원문(F-2).
- SketchCAD 매뉴얼, 저장소 이력(얕은 복제라 커밋 하나만 보임).
