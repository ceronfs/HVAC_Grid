# V2-1 검토 — 덕트 엔진 (게이트 K2)

작성 2026-10-26 · 범위: `v2` 브랜치 V2-1 커밋(K1 `ef5874f` 뒤) · 계획: [PLAN_V2_WORK.md](PLAN_V2_WORK.md) V2-1 · 기능 명세: [STUDY_PHG.md](STUDY_PHG.md) · 결정: D7(새로 짬)·D8(같은 기능, 차이 기록)·D12·D14 · 실행: 클라우드 Linux, Node 22, Chromium(브라우저 시험)

④ RU·덕트의 경로(AUTO)·덕트 지정·크기·압력을 **PHG D 창 없이** 계산하는 엔진을 `lib/duct/`에 새로 짰다. PHG D 코드는 가져오지 않았다(D7). 이음쇠 표의 **값**만 PHG D와 같게 썼다(D14).

## 1. 강제 항목

| 항목 | 결과 | 근거 |
|---|---|---|
| F-1 풍량은 여름 기준 하나 | **지킴** | 엔진의 풍량 입력은 계획의 RU 풍량(계약의 여름 풍량) 하나뿐이다(`lib/duct/input.cjs`). 난방·겨울 풍량 입력·경로가 없다. 풍량 계산(`lib/contract.cjs`)은 바꾸지 않았다. `test/iso7547.test.cjs` "one airflow all year"·`contract.test.cjs` 통과(`npm test` 160/160) |
| F-2 표준 값은 원문으로 | **지킴(원문 미확인 표시)** | ASHRAE 이음쇠 값(CR3-1, CR3-3, SR5-13, ER5-3)은 PHG D가 쓰는 값을 그대로 옮기고 `lib/duct/pressure.cjs` 머리와 각 표에 "원문 미확인"을 적었다(D14). 속도 10/8/8 m/s, 최소 높이, 300·500·800 mm 규칙, 보온·여유 25 mm는 표준 인용이 없는 프로그램 기본값이다(`input.cjs`, `size.cjs`에 그렇게 적음). ISO 7547 값은 이 단계에서 쓰지 않았다. **원문 대조가 남았다**(5장 결정 4) |
