## 개선 제안 (우선순위)

1. **계통도 추가** — 계통별 공조기 → 샤프트 → Deck별 덕트(CMH·크기·ESP) 계통도를 ⑤ 화면·보고서·DXF에. 데이터는 이미 있음(`analysis().systems`, `risers`).
2. L1·L2 수정(T3 창 일사, 급기 안전율 기준을 정하고 문서·코드 일치).
3. A1: AUTO 뒤 수동 크기 다시 적용, 모든 계통 AUTO를 실행 취소 기록에, ④에도 "남은 것만".
4. L4 실별 최소 외기 검사, A2 공조기 위치 검사, L3·L5 경계 조건.
5. A3~A5 화면·안내 정리, 나머지 P3.

세부 재현 절차·증거: `out/review/tester/REPORT.md`, `out/review/loads/REPORT.md`.

## 조치 (2026-10-20)

- **L1 고침**: T3 생성기에 창 일사(Gs 240) 설정, T3 v2.3 다시 생성. 냉방 현열 75.8 → 88.7 kW.
- **L2 고침**: 급기 = 냉방 현열 × 안전율(`conditions.safetyFactorPct`) × 3 ÷ ΔT. S5 급기 10,610 → 11,510 CMH, T3 21,700 → 27,760 CMH(창 일사·조리실·배식실 배기 상향 포함). 문서(CONTRACT.md)·도움말·보고서 풍량 규칙 문구도 맞춤.
- **A1 고침**: AUTO가 덕트망을 다시 만들 때 수동 크기를 같은 이름·종류의 덕트에 다시 적용하고 몇 개 유지/다시 지정 필요인지 알림. PHG D 편집기 수정은 다시 만들어짐을 알림(Ctrl+Z). 모든 계통 AUTO·남은 것만은 실행 취소 1단계로 기록.
- **개선 1 계통도**: `lib/diagram.cjs` — 계통마다 공조기·팬 → 수직 덕트(구간별 크기·풍량·풍속·방화댐퍼) → Deck별 덕트망(풍량·RU·덕트 개수·길이·Deck 손실 + 수직 손실 = 합계), 최대 손실 Deck(ESP) 굵은 테두리. ⑤ "계통도" 탭(Deck 상자 두 번 클릭 → ④), HTML 보고서 "계통도" 장, 통합 DXF(Deck 평면 아래, DIAGRAM_SUPPLY/EXHAUST/RETURN/TEXT/GRID 레이어). 함께: DXF 수직 덕트 글자 겹침(P3-13) 고침, ③ 속성 패널 풍량 규칙에 안전율 표시.
- **P2 고침 (L3·L4·L5·A2·A3·A4·A5)**
  - L4 실별 최소 외기: 재순환 구역에서 실 신기 = 급기 × 구역 신기 % 가 그 실 최소 신기보다 작으면 확인 항목(필요한 급기 또는 신기 비율을 함께 표시). S5 10실, T3 4실.
  - A2 공조기·수직 덕트 위치: 계단·승강기·탈출 트렁크, CO₂실, 조리실, A류 기관구역, 보일러실, 페인트·가연성 액체 창고, 화물 구역에 두면 확인 항목 + 놓는 순간 경고(실 이름 표시).
  - L3·L5 T3 v2.4: 최하층 바닥 = 아래 기관실(NON_AC 43/5 °C, BOX 면 경계 지정), 기관실 케이싱 43/5 °C, 계통 없는 창고·팬룸·공조기실·트렁크 = 비공조(NON_AC, 32/10 °C). T3 난방 60.2 → 53.9 kW(D1 23.1 → 14.5 kW). 세탁실 배기 40 → 45회/h(부압 유지).
  - A3 1280 px: BOX 화면의 Deck이 떠 있는 패널 밑으로 들어가면 BOX 보기를 패널 사이로 옮김(1600 px에서는 ②와 픽셀 일치 그대로). 좁은 창에서 리본 간격·입력칸 축소 — ③ 리본이 스크롤 없이 들어감.
  - A4 계통 0개(H5·DXF 도면): 설계 데이터 만들기 직후 알림, "다음" 안내 = ② 격실 입력에서 계통 지정.
  - A5 예제: ③ 리본에서 뺌(①에 있음). 빈 화면의 예제 단추는 도면(BOX)을 열고 그 도면으로 설계 데이터를 만듦 — ①·② 가 비지 않음. T3는 SOLAS 최하층 아래 설정까지.
