HVAC Grid 도움말

작업 순서

  1. ① 도면·격실 — BOX에서 일반배치도 DXF를 열고 외곽선·실 번호·실 지정으로 격실을 만듭니다. 연습은 리본 예제의 S5·T3로.
  2. ② 부하 — 격실 입력에서 실마다 계통(SUP·EXH·RET)·인원·신기·장비 발열을 확인·입력하고, 설계 조건·K값(ISO·LY·사용자)을 정한 뒤 설계 데이터 만들기. CAL은 뒤에서 계산하고(상태 줄에 격실 수) 표는 따로 창으로 열립니다.
  3. ③ 풍량·계통 — 급기 ΔT·가압·최소 신기를 정하고 적용. 계통별로 공조기(공조기 Deck)나 수직 덕트 위치를 평면에서 지정합니다. 방화 보기로 SOLAS 경계를 확인합니다.
  4. ④ RU·덕트 — ③과 같은 평면에서 모든 계통 AUTO(또는 계통 하나씩 보내기 + AUTO). PHG D는 뒤에서 경로·크기·압력을 계산하고 덕트망은 이 평면에 그려집니다. 평면에서 바로: RU·공조기를 끌어서 옮기면 다시 AUTO, 덕트를 누르고 크기를 고르면(풍속 표시) PHG D가 그 크기를 지키며 다시 계산, 다른 경로는 AUTO의 다음 후보. 그 밖의 세부 편집은 PHG D 편집기 → 평면으로(고친 내용을 읽어 옴).
  5. ⑤ 검토·출력 — 검토 실패·확인을 보고 고친 뒤 프로젝트 저장, 통합 XLSX·DXF·보고서.

상태 줄 왼쪽의 다음: 단추가 지금 할 일을 알려 줍니다.

용어

설계 데이터
② 부하에서 BOX의 Deck·격실·부하를 받아 만든 묶음. ③ 풍량 규칙·계통이 더해지고, ③~⑤가 이것으로 계산
LY · LY 적용
구조 레이어(강판·단열·내장)로 계산한 K값 보기 · 그 K값을 면별 경계에 적용 (ISO 기준 · ISO 적용과 짝)
급기 (SA)
실로 보내는 공기. 냉방 현열 W × 안전율(BOX 설계 조건, 기본 1.10) × 3 ÷ ΔT, 최소 신기 이상
배기 (EA)
실에서 밖으로 버리는 공기 (화장실·조리실 등). 환기 횟수 × 체적
환기 (RA)
공조기로 되돌리는 공기. 공조 구역 수지로 정함
신기 (OA)
바깥 공기. 구역마다 최소 신기·배기 + 가압·최소 신기 비율 중 큰 값
전달 공기
배기만 있는 실이 이웃 실에서 문 그릴로 받는 공기. 실 정보에서 출처 지정
RU
디퓨저·그릴 같은 말단 (500 CMH마다 1개)
공조기 · 수직 덕트
계통의 시작점. 공조기 Deck에는 공조기·팬, 다른 Deck에는 수직 덕트(샤프트)
AUTO
PHG D 자동 경로. 제한 구역·선체 밖은 금지 영역으로 피함
ESP · 팬 정압
덕트 외부 정압(Deck 최대 + 수직 덕트) · 팬 정압 추정(ESP + 공조기 내부 + 루버)
A-60 · A-0 · B-0
SOLAS 방화 등급. 덕트가 지나면 관통 조치(슬리브·방화댐퍼)

파일

  • 프로젝트(.json) — 설계 데이터 + 모든 PHG D 덕트망 + 결과. 다시 열면 AUTO 없이 그대로.
  • 설계 데이터(.json, ③ 리본) — 격실·부하·풍량·계통만.
  • 출력(⑤ 리본) — 통합 XLSX(14시트), 통합 DXF(R12), 보고서(HTML, A4 가로 인쇄), 요약 CSV.
  • 폴더 단추 메뉴에 최근 프로젝트가 있습니다. 저장 안 한 변경이 있으면 창 제목에 * 가 붙습니다.

문제가 생기면

  • 오류는 화면 아래 알림과 상태 줄 오른쪽에 나옵니다. 잘못 넣은 칸은 빨갛게 표시됩니다.
  • 실행 과정 보기: HVAC_Grid.bat console · 기록: %LOCALAPPDATA%\HVAC_Grid\launch.log
  • 설계 보조 결과입니다. 최종 판단은 설계자·주관청·선급에 따릅니다.
